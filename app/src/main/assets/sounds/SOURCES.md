# 소리 에셋 출처

모든 파일은 [scripts/audio/make_sounds.py](../../../../../scripts/audio/make_sounds.py)로 **직접 합성**했습니다. 외부 음원·샘플·저작권 곡을 쓰지 않았습니다(F4.1).
사인파, 잡음(고정 시드), 감쇠 엔벨로프만으로 만들며, 스크립트를 다시 돌리면 같은 파일이 나옵니다.

| 파일 | 내용 |
|---|---|
| beat_{sea,forest,space}_l1~l4.wav | 테마별 120 BPM 4마디(8초) 루프를 악기 레이어 4개로 나눈 모노 파일(F4.4). l1 킥·하이햇(숲은 셰이커)·통통 튀는 베이스, l2 스네어·클랩·필인, l3 멜로디(바다 마림바 C장조, 숲 플루트 G장조, 우주 신스 A단조), l4 엇박 코드·잔타악기. 앱이 좌우 소리 수에 따라 섞는다 |
| cue_left.wav | 왼쪽 소리. 낮은 나무 소리 두 번, 내려가는 음. 왼쪽 채널만 |
| cue_right.wav | 오른쪽 소리. 높은 종소리 두 번, 올라가는 음. 오른쪽 채널만 |
| star_lost.wav | 별이 떨어질 때. 내려가는 종소리 세 음 |
| chime.wav | 알림. 올라가는 종소리 두 음 |

좌우 소리는 스테레오 패닝에 더해 **음색과 음높이로도** 구분되게 했습니다. 실제 차량 스피커 배치에서 뒷자리가 좌우를 구분하는지는 실차에서 확인해야 합니다.
