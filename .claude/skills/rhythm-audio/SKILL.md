# 리듬 오디오 (app/audio)

core가 내는 Effect를 소리로 바꾸는 쪽이다. 언제 소리를 낼지는 core가 정하고, 여기서는 **어떻게** 낼지만 다룬다.

## Effect → 소리
| Effect | 재생 |
|---|---|
| `StartBeat(theme)` | 테마의 기본 루프(레이어 1) 시작 |
| `SetLayer(n)` | 다음 마디 경계에서 레이어 1..n을 켠다. 즉시 바꾸면 박자가 어긋난다 |
| `PlaySideCue(side, withVoice)` | 좌/우 효과음을 **즉시** 재생. `withVoice`면 "왼쪽!"/"오른쪽!" 음성을 겹쳐 재생 |
| `StarLost` | 짧은 효과음 |
| `StopBeat` | 짧게 페이드아웃 후 정지, 오디오 포커스 반납 |
| `Chime` | 제안 전 짧은 알림음 |

## 구현 규칙
- **좌우 효과음은 지연이 짧아야 한다.** 차가 도는 순간과 소리가 맞아야 의미가 있으므로 `SoundPool` 등으로 미리 로드하고, Effect를 받은 시점부터 재생까지의 지연을 로그로 남긴다. 목표 지연은 사용자와 정한다.
- 좌우 구분은 스테레오 패닝(왼쪽 = L 채널)으로 한다. 실제 차량 스피커 배치에서 뒷자리가 좌우를 구분할 수 있는지는 에뮬레이터에서 확인할 수 없으므로 한계로 기록한다.
- 루프와 레이어는 같은 BPM과 같은 마디 길이로 만든다. 1차는 테마당 레이어 4개짜리 루프 1세트로 한다.
- **사운드 에셋은 직접 만든 것만 쓴다**(F4.1 "앱이 직접 만든"). 저작권이 있는 곡이나 출처가 불분명한 샘플을 넣지 않는다. 에셋마다 제작 방법을 `app/src/main/assets/sounds/SOURCES.md`에 적는다.
- "왼쪽!"/"오른쪽!" 음성은 TTS로 매번 합성하면 늦을 수 있으니 미리 합성하거나 녹음 파일로 둔다.

## 오디오 포커스 (S6, pleos-sdk 검증 항목 4)
- 내비 안내가 항상 우선이다. 내비 안내가 나오면 비트는 덕킹(볼륨 낮춤)하거나 멈춘다. 좌우 효과음은 내비 안내 중에는 생략한다.
- 재생 중인 음악이 있을 때 비트를 섞을지 멈출지는 검증 항목 4의 결과를 보고 정한다. 결과 전에는 짐작으로 구현하지 않는다.
- 포커스 요청 방식, 사용할 AudioAttributes usage는 Pleos/AAOS 문서에서 확인한 뒤 `pleos-sdk/references/audio.md`에 정리하고 따른다.
- 포커스를 잃으면 core에 알린다(`AudioInterrupted`). 이때 판 진행과 별 판정은 계속된다.
