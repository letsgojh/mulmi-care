# 시연 영상 시나리오 — 한계령

목표 길이: **2분 30초 안팎**(편집 후). 원본 녹화는 약 9분입니다.
재생 스크립트: [scripts/emulator/demo.sh](../scripts/emulator/demo.sh). 장면이 바뀔 때 `=== 장면 N`, 주행 토막이 바뀔 때 `=== 토막 N`(편집점)을 출력합니다.

## 왜 한계령인가
멀미케어는 **구불길에서만** 놀이를 제안합니다. 실제 한계령(44번 국도) 도로 좌표로 주행을 재현해, 곧은 길에서는 조용하다가 고갯길에 들어서면 묻고, 커브 방향대로 좌우 소리가 나는 모습을 보여 줍니다.

- 경로: 인제 원통 → 한계령휴게소 → 오색 → 양양 (약 48km). 좌표 출처: © OpenStreetMap contributors(ODbL), OSRM으로 계산
- 재현 방식([drive_route.py](../scripts/emulator/drive_route.py)): 커브 반경에 맞춰 속도를 줄이고(옆 가속도 2m/s² 이하), 곡률로 앞바퀴 각도를 구해 조향비 14를 곱한 핸들 각도를 0.1초마다 Virtual Console로 보냄
- **에뮬레이터 내비는 위치를 바꿀 수 없습니다**(GPS를 넣어도 판교에 고정). 그래서 같은 주행을 **주행 재현 지도**(브라우저, `http://127.0.0.1:8090/map/`)에 따로 보여 줍니다. 영상 자막에 "주행 재현 지도"라고 밝힙니다.

## 화면 배치

| 영역 | 보이는 것 |

| 에뮬레이터 왼쪽 | 계기판: 속도, 기어. 속도가 있으면 주행 화면(도로·앞차)으로 바뀜 |
| 에뮬레이터 오른쪽 | 내비 경로 안내(목적지 오색약수). 멀미케어는 화면을 가리지 않음(S1) |
| 에뮬레이터 하단 | 공조 온도 22.0 → 21.0(기본) → 19.5(강화) → 22.0(되돌리기) |
| 옆 창(브라우저) | 주행 재현 지도: 한계령 길 위 내 위치, 속도, 핸들 각도 |

멀미케어는 소리로만 동작합니다. 앱이 하는 말과 좌우 소리는 자막으로 넣습니다.

## 녹화 준비

1. 에뮬레이터 **Cold boot**, 최신 디버그 APK 설치: `adb install -r -g app/build/outputs/apk/debug/app-debug.apk`
2. 소리: 녹화 프로그램이 **PC 소리(데스크톱 오디오)**를 함께 녹음하도록 설정. Windows 볼륨 믹서에서 `qemu-system-x86_64` 음량 확인
3. 응답 방식
   - 자동(기본): 스크립트가 마이크를 끄고 adb로 답을 넣음. 주변 소리에 놀이가 끊기지 않음
   - 직접 말하기(`VOICE=1`): 스크립트가 마이크를 켬. **조용한 곳에서**, PC 영상·음악을 끄고
4. 녹화 도구: OBS(에뮬레이터 창 + 재현 지도 브라우저를 나란히) 또는 Windows `Win + Alt + R`(창 하나)

## 녹화

```bash
bash scripts/emulator/demo.sh            # 응답 자동
VOICE=1 bash scripts/emulator/demo.sh    # 직접 말하기
```
"준비 끝 … 녹화를 시작하세요"가 나오면 녹화를 시작하고, 브라우저에서 재현 지도를 엽니다. "끝. 녹화를 멈추세요"에서 멈춥니다.

## 편집

- 토막 사이(`=== 토막 N`)는 순간 이동한 편집점입니다. 자막: "고갯길로" / "고개를 넘어 양양 방향 곧은 길"
- 장면 4의 곧은 길 대기(약 2분)는 줄이고 "2분 뒤" 자막
- 좌우 소리는 스피커로 구분이 어려우니 **"🔊 오른쪽"** 자막을 꼭 넣기
- 장면 5는 에뮬레이터 내비가 위치 고정이라 도착 이벤트를 재현한 것: "(도착 상황 재현)"

## 공개 전 확인 (공모전 안내)
- 영상·자막에 **실명·연락처·계정 정보**가 보이지 않는지(알림, 브라우저 탭·즐겨찾기, 작업 표시줄 포함)
- 재현 지도 화면 하단의 OpenStreetMap 출처 표기가 보이게 두기
- 음성에 이름이 나오지 않는지
