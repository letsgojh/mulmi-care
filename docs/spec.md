# 멀미케어 요구사항 명세

기획서 원문([plan-original.md](plan-original.md))에서 구현할 규칙만 뽑아 ID를 붙였습니다.
테스트 이름과 커밋 메시지에서 이 ID를 씁니다. 원문과 이 문서가 다르면 원문이 맞고, 이 문서를 고칩니다.

`TBD`는 기획서에 값이 없어서 시험으로 정할 값입니다. 코드에서는 `Thresholds` 설정에 기본값을 두고, 테스트는 설정값을 주입받아 씁니다.

## F1. 출발 전 설정
| ID | 규칙 |
|---|---|
| F1.1 | 내비 목적지까지 예상 소요가 **30분 이상**이고 **정차(P단)** 상태면 "케어를 켤까요?"를 **한 번** 묻는다 |
| F1.2 | 30분 미만 이동에서는 케어를 기본으로 꺼 둔다 |
| F1.3 | 고를 항목: 뒷자리 탑승자(아이 / 성인), 리듬 놀이 제안 여부(제안받기 / 묻지 않기), 종이배 모양, 음악 테마 |
| F1.4 | "케어 시작"을 눌러야 케어가 켜진다 |
| F1.5 | 탑승자가 성인이면 놀이 없이 실내 케어와 쉬어 가기만 제공한다 |

## F2. 아이를 위한 30초 연습
| ID | 규칙 |
|---|---|
| F2.1 | **처음 사용할 때만** 정차 상태에서 자동으로 보여 준다. 이후에는 원할 때만 다시 본다 |
| F2.2 | 왼쪽 소리와 오른쪽 소리를 한 번씩 들려주고, 화면의 종이배가 같은 쪽으로 기운다 |
| F2.3 | 규칙 안내: "굽은 길에서 음악이 나오면 시작, 앞을 보면서" |
| F2.4 | 30초 안팎이며 건너뛸 수 있다 |
| F2.5 | 실제 놀이의 처음 몇 번(`TBD`, 기본 3회)은 소리와 함께 "왼쪽!"/"오른쪽!"을 말로 알리고, 그 뒤로는 소리만 낸다 |

## F3. 리듬 놀이 제안
| ID | 규칙 |
|---|---|
| F3.1 | 놀이는 **자동으로 시작하지 않는다** |
| F3.2 | 굽은 길 구간에 들어서면 짧은 알림음 + "리듬 놀이 할까요?"를 **한 번만** 묻는다 |
| F3.3 | "응"이라고 답할 때만 시작한다. 답이 없거나 거절하면 시작하지 않는다 |
| F3.4 | 거절하거나 답이 없으면 이후 **15분** 동안 다시 묻지 않는다 |
| F3.5 | 놀이 중 "그만"이라고 하면 바로 끝낸다 |
| F3.6 | 음성 인식은 **앱이 물어본 직후**와 **놀이 중**에만 받는다 |
| F3.7 | 직선 도로와 고속도로에서는 제안하지 않는다 (굽은 길 구간이 아니면 제안하지 않음) |
| F3.8 | F1.3에서 "묻지 않기"를 고른 경우 제안하지 않는다 |

## F4. 주행이 악보가 되는 리듬 (핵심)
| ID | 규칙 |
|---|---|
| F4.1 | 놀이가 시작되면 앱이 직접 만든 단순한 비트를 깐다 |
| F4.2 | 굽은 길: 조향각이 일정 값(`TBD`) 이상 변하기 **시작하는 순간** 그 방향의 좌/우 소리를 낸다 (예고가 아니라 동시 신호) |
| F4.3 | 교차로·나들목·차로 변경: **방향지시등 점등** 시 그 방향 소리를 낸다 (차가 움직이기 전 예고) |
| F4.4 | 길이 곧으면 비트가 잔잔해지고, 회전이 이어지면 악기가 하나씩 더해진다 (1차는 단순한 형태) |
| F4.5 | 정해진 곡을 따라가지 않는다 |
| F4.6 | 아이의 동작은 채점하지 않는다 |
| F4.7 | 내비 회전 안내를 받을 수 있으면 굽은 길에서도 예고하도록 확장한다 (2단계, 1차 범위 아님) |

## F5. 별을 지키는 가족 팀 게임
| ID | 규칙 |
|---|---|
| F5.1 | 한 판 = 굽은 길 구간 하나 (2~5분) |
| F5.2 | 별 3개로 시작한다 |
| F5.3 | 급한 조향(조향각 변화 속도 기준, `TBD`) 또는 급한 감속(차량 속도 변화율 기준, `TBD`)마다 별이 하나씩 떨어진다 |
| F5.4 | 결과는 3, 2, 1개 중 하나다 (**최소 1개**) |
| F5.5 | 별이 떨어질 때는 짧은 효과음으로만 알리고 주행 중 화면에 표시하지 않는다 |
| F5.6 | 운전자의 주행을 음성으로 지적하지 않는다 |
| F5.7 | 판이 끝나면 "종이배 도착! 별 N개를 지켰어요"를 말하고 음악을 끈 뒤 조용해진다 |
| F5.8 | 누적 별이 쌓이면 돛·깃발이 열린다 (예: 별 5개마다 하나, `TBD`) |

## F6. 실내 자동 케어
| ID | 규칙 |
|---|---|
| F6.1 | 케어가 켜져 있으면 놀이 여부와 관계없이 동작한다 |
| F6.2 | **기본 단계**: 외기 유입, 설정 온도 −1℃ |
| F6.3 | **강화 단계**: 기본에서 설정 온도를 1~2℃ 더 낮춤(`TBD`), 풍량 +1단계, 풍향 상체 |
| F6.4 | 강화 단계 진입 조건: 굽은 길 구간 진입, 또는 "힘들어해요" 응답 |
| F6.5 | 구간이 끝나고 **5분** 뒤 기본 단계로 돌아간다 |
| F6.6 | 겨울(바깥 기온 낮음): 온도 낮추는 폭을 줄이고, 하한값(`TBD`) 아래로 내리지 않는다. 대신 외기 유입과 상체 바람으로 보완 |
| F6.7 | 바깥 기온을 조회할 수 없으면 날짜로 계절을 판단한다 |
| F6.8 | 제어를 요청한 뒤 상태를 다시 읽어 반영됐는지 확인한다 |
| F6.9 | 창문 개폐는 하지 않는다 |

## F7. 뒷자리 상태 확인과 쉬어 가기
| ID | 규칙 |
|---|---|
| F7.1 | 굽은 길 구간이 끝나면 "뒷자리는 괜찮아요?"라고 묻는다 |
| F7.2 | "힘들어해요"(음성 응답 또는 정차 중 버튼)이면 강화 단계로 바꾸고 쉬어 갈 곳을 제안한다 ("8km 앞에 쉼터가 있어요. 들를까요?") |
| F7.3 | 수락하면 가까운 휴게소/쉼터를 내비 경유지로 추가한다. **좌표가 없는 경로 위 쉼터(내비 회전 안내로 찾은 것)는 경유지 대신 "가는 길에 있어요. 입구가 나오면 들어가세요"라고 안내한다** (2026-11-15 변경: 내비 회전 안내에는 좌표가 없음) |
| F7.4 | 쉼터는 1차로 **내비 회전 안내의 휴게소·쉼터 항목**으로 찾는다. 좌표가 있는 공개 위치 데이터(OSM 등)는 보강 예정 |

## F8. 정차 중에만 보이는 화면
| ID | 규칙 |
|---|---|
| F8.1 | **주행 중에는 화면에 아무것도 띄우지 않는다** |
| F8.2 | 정차하면 "항해 지도"를 보여 준다: 오늘의 길이 강처럼 그려지고, 판마다 종이배와 지킨 별, 남은 굽은 길은 빈칸 |
| F8.3 | 새로 열린 돛·깃발을 골라 배를 꾸민다 |

## F9. 도착 후 리포트
| ID | 규칙 |
|---|---|
| F9.1 | 판 수, 지킨 별, 흔들린 구간을 물결 모양 기록으로 보여 준다 |
| F9.2 | 뒷자리 상태를 한 번의 터치로 남긴다 |
| F9.3 | 뒷자리가 자주 힘들어했다면 다음 이동은 처음부터 강화 단계로 시작한다. 기록은 놀이 제안 빈도에도 반영된다: 그런 이동에서는 거절·무응답 뒤 다시 묻지 않는 시간(F3.4)을 15분에서 10분(`TBD`)으로 줄인다 |

## D. 구간 판단

| D2 | 구간 종료: 기준 아래로 **1분** 유지 |
